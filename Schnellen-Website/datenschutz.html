Diese Website

Diese Informationsseite setzt keine eigenen Cookies, verwendet keinen lokalen Browserspeicher und enthält keine Analyse-Tools, Werbetracker oder Kontaktformulare. Schriftarten kommen von deinem Gerät; Bilder und Stylesheets werden direkt mit der Website ausgeliefert.

Bereitstellung über GitHub Pages

Bei Veröffentlichung auf GitHub Pages wird die Website von GitHub bereitgestellt. GitHub protokolliert und speichert die IP-Adresse von Besuchern zu Sicherheitszwecken. Einzelheiten zu den durch GitHub verarbeiteten Daten, Speicherfristen, internationalen Übermittlungen und deinen Rechten findest du in der Datenschutzerklärung von GitHub. Siehe auch die Informationen zur Datenerhebung bei GitHub Pages.

Externe Links und E-Mail

Links zum App Store und zu anderen Websites werden erst beim Anklicken aufgerufen. Dort gelten die Datenschutzinformationen des jeweiligen Anbieters. Der E-Mail-Link öffnet dein E-Mail-Programm; diese Website selbst übermittelt dabei keine Nachricht. Sende nur die Informationen, die für deine Anfrage erforderlich sind.

Daten in der App

Die App und diese Website sind getrennte Angebote. Die App verarbeitet unter anderem Daten für Online-Spiele, Profile und Freundeslisten. Maßgeblich sind die Informationen in der Datenschutzerklärung für Schnellen. Deine Profildaten kannst du in der App im Konto-Bereich unter Datenschutz löschen.
